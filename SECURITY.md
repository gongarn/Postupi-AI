# Security Policy

## Приватность — это фича

Postupi AI обрабатывает только публичные конкурсные списки и не имеет
доступа к личным кабинетам, Госуслугам, cookies или закрытым системам.
Идентификаторы абитуриентов хранятся исключительно в виде namespaced
HMAC-SHA256 хэшей; raw UID не сохраняется в БД, логах, API-ответах,
фикстурах и тестах.

## Сообщение об уязвимости

Нашли уязвимость или утечку приватности — **не открывай публичный Issue**.
Напиши приватно мейнтейнерам проекта на GitHub (Security tab → Report a
vulnerability). Опиши:

- затронутый компонент и версию;
- шаги воспроизведения;
- влияние на приватность пользователей (критично: раскрытие чужих данных,
  утечка `POSTUPI_UID_HMAC_SECRET`, `POSTUPI_INTERNAL_API_TOKEN`,
  `POSTUPI_TELEGRAM_BOT_TOKEN`).

## Области повышенного внимания

- HMAC-секрет и внутренний API-токен: никогда не логировать, не коммитить,
  не возвращать в ответах.
- Любой новый код, который раскрывает чужие ID, баллы, позиции или
  предпочтения, — отклоняется.
- Внутренний API доступен только с `X-Internal-Token` (сравнение через
  `compare_digest`).
- Raw payload источников не сохраняется (`DiscardingRawSnapshotStorage`).
- Внешние зависимости: следи за обновлениями (aiogram, FastAPI, SQLAlchemy,
  arq), которые затрагивают безопасность.
