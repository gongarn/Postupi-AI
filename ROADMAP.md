# Postupi AI — Roadmap

Бесплатный open source (MIT) сервис анализа шансов поступления по публичным
конкурсным спискам. Никакого сбора персональных данных, никаких чёрных
ящиков: только публичные источники, HMAC-приватность и прозрачная
Monte Carlo-модель.

## Миссия

Каждый абитуриент должен понимать свои реальные шансы поступления, не платя
за тревогу и не отдавая свои данные. Платные боты и «калькуляторы шансов»
зарабатывают на страхе — мы делаем бесплатную, проверяемую альтернативу,
которую может поднять и развивать любой желающий.

## Принципы (не обсуждаются)

1. **Только публичные данные.** Никаких личных кабинетов, Госуслуг, cookies.
2. **Приватность.** Raw идентификаторы абитуриентов не хранятся (namespaced
   HMAC-SHA256). Прогнозы не раскрывают чужие данные.
3. **Прозрачность.** Модель прогноза открыта и объяснима: каждый параметр
   описан, симуляции детерминированы, explanation содержит только агрегаты.
4. **Бесплатно навсегда.** MIT-лицензия: код можно копировать, изучать,
   поднимать свой инстанс. Прогноз не является гарантией зачисления — мы
   никогда не продаём «гарантии».
5. **Данные — общее благо.** Агрегаты конкурсных списков (проходные баллы,
   динамика, конкурс) публикуются открыто (CSV/JSON) для абитуриентов,
   журналистов и исследователей. Сырые списки с ФИО не публикуются (152-ФЗ).

## Фаза 1 — Данные, калибровка и сайт-витрина (октябрь 2026 – апрель 2027)

Кампания 2027 — приоритет: бот остаётся основным трекером (он уже готов),
сайт строится как витрина данных без личных кабинетов.

- [ ] Расширение источников по матрице `docs/data_feasibility_audit.md`
      (аудит 0A.2 — ещё 12 вузов).
- [ ] Калибровка `probabilistic-2` по итогам кампании 2026 (backtest) +
      релиз архива агрегатов 2026.
- [ ] Бот: поиск группы по названию, упрощённый онбординг (вход по коду без
      ручной заливки данных).
- [ ] Сайт-витрина (FastAPI + Jinja2 + HTMX + Alpine.js, SSR без SPA):
      страницы вузов и направлений с проходными баллами по годам
      (2024→2025→2026), тренды и конкурс. Без регистрации и кабинетов.
- [ ] Сайт: калькулятор «мои баллы ЕГЭ → куда я прохожу с запасом / впритык /
      не прохожу» на основе архивов прошедших кампаний.
- [ ] Открытые данные: выгрузки CSV/JSON только агрегатов (проходные баллы,
      динамика, конкурс) — без ФИО и сырых списков (152-ФЗ).

## Фаза 3 — Развитие (после 2027)

- [ ] Веб-трекер позиции на сайте (по ссылке-токену, без аккаунтов) — когда
      появится ресурс; бот остаётся основным трекером.
- [ ] Мобильный web (PWA), экспорт трека.
- [ ] Self-host гайд для вузовских сообществ и школ.
- [ ] Аналитика кампаний: сравнительные отчёты по вузам и направлениям.

## Как помочь

- Подключить новый вуз: свежий аудит по шаблону `docs/university_audit_report_template.md`.
- Поддерживать парсеры: вузы меняют сайты, нужны быстрые фиксы.
- Тестировать бота в реальной кампании.
- Дизайн, UX, переводы, документация.

Все идеи и баги — в Issues. Главное правило: ничего из этого списка не
должно стать платным.
