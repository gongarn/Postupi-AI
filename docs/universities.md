# Целевая матрица вузов

Целевой охват продукта: топовые вузы Москвы по трём тирам (деление по
RAEX-100 2025 и агрегированным метрикам качества приёма). Уже подключены
(2026): ИТМО (primary pilot), ВШЭ (controlled pilot), МФТИ (monitor-only).

> Статус источника (формат списков, доступность без авторизации, наличие
> UID/согласий/приоритетов) для всех новых вузов определяется аудитом 0A.2
> по шаблону `university_audit_report_template.md`. Ниже — плановая
> приоритизация, не подтверждённые факты.

## Стратегия

1. **Тир 1 → сезон 2027** (приоритет разработки): МГУ, Бауманка, МИФИ,
   МГИМО, ФинУнивер, РНИМУ, Сеченовка; МФТИ продвигается из monitor при
   успешном аудите 2026; ВШЭ и ИТМО уже работают.
2. **Тир 2 → 2027–2028**: МИСИС и РЭУ сразу после сезона 2027, остальные —
   по заявкам и свободному времени.
3. **Тир 3 → краудсорсинг**: гайд подключения, шаблон аудита, ревью
   контрибьюторов мейнтейнером.
4. Медицинские вузы (Сеченовка, РНИМУ) — запасные кандидаты при
   недоступности списков: МЭИ, Губкин, РУДН (тир 2).

## Критерий включения вуза в продукт

Публичные списки без авторизации; наличие UID абитуриента, условия
(бюджет/особая квота и т.п.), ранга, согласия и приоритета; стабильный
формат (SSR HTML / API / XLSX); возможность HMAC-нормализации без хранения
raw идентификаторов. Прогнозы — только после валидации namespace и числа
мест (по образцу ИТМО/ВШЭ).
