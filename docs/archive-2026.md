# Шаг 1 — Архив кампании 2026 (дедлайн: 9–11 августа 2026)

## Цель

Сохранить финальные конкурсные списки кампании 2026 **до их исчезновения**
и собрать приказы о зачислении — это единственный источник меток
«прошёл/не прошёл» для калибровки `probabilistic-2` к сезону 2027.
После 15 августа списки 2026 будут заменены/удалены вузами.

## Состав работ

### 1. Инфраструктура (30–60 мин)

- [ ] `docker compose up -d postgres redis`
- [ ] `.env`: `POSTUPI_UID_HMAC_SECRET`, `POSTUPI_INTERNAL_API_TOKEN`,
      `POSTUPI_DATABASE_URL=postgresql+asyncpg://postupi:postupi@localhost:5432/postupi`
- [ ] `alembic upgrade head` (или `make migrate` в docker)
- [ ] Smoke: `uvicorn apps.api.main:app` + `/health/ready`

### 2. Финальные snapshot'ы — три прогона

Прогон A (8–9 авг, до 12:00): текущее состояние.
Прогон B (9 авг, после приказов 2-й волны).
Прогон C (11–12 авг, после приказов МГУ) — финальный.

Каждый прогон:

- [ ] ИТМО: `python -m apps.worker.itmo_ingestion` (полный batch)
- [ ] ВШЭ: `python -m apps.worker.hse_ingestion`
- [ ] Универсальный ингейшн 8 вузов:
      `POSTUPI_ACTIVE_UNIVERSITIES=rnimu,mpei,misis,fa,stankin,msu,rudn,sechenov
       python -m apps.worker.universal_ingestion` (или через job)
- [ ] Зафиксировать сводку: сколько snapshot'ов/заявлений по каждому вузу
      (в `/tmp/archive2026/progon_X.md`)

Ограничения: МГУ — полный обход 39 факультетов (~230 МБ) — выполнять
после 12:00 9-го числа; РУДН — лимит 60 групп; ФинУнивер — один snapshot
на вуз.
