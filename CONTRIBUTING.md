# Contributing

Спасибо, что помогаешь делать бесплатный сервис анализа шансов поступления
лучше. Несколько простых правил, чтобы всем было комфортно.

## Как внести вклад

1. Открой Issue (баг, фича, «добавить вуз») — коротко опиши проблему или
   идею. Для нового вуза используй шаблон аудита
   `docs/university_audit_report_template.md`.
2. Сделай fork, создай ветку от `main`, внеси изменения.
3. Убедись, что проверки проходят:
   ```powershell
   ruff check .
   mypy apps packages
   pytest -q
   ```
4. Открой Pull Request со ссылкой на Issue.

## Что ценно

- Поддержка парсеров: вузы меняют сайты — быстрые фиксы очень важны.
- Новые вузы: свежий аудит по шаблону из `docs/`.
- Тесты, документация, UX бота, дизайн, переводы.
- Отчёты о неточностях прогнозов (без персональных данных).

## Чего не делать

- Не добавляй в Git `.env`, секреты, реальные UID абитуриентов, сырые ответы
  источников, cookies, логи и локальные артефакты.
- Не ломай приватность: raw UID храниться не должен (только namespaced HMAC).
- Не превращай проект в платный: коммерческие «гарантии поступления» и
  продажа пользовательских данных противоречат миссии проекта.

## Вопросы

Архитектура и инварианты описаны в [AGENTS.md](AGENTS.md), план — в
[ROADMAP.md](ROADMAP.md). Если сомневаешься — спроси в Issue, прежде чем
делать большую работу.
